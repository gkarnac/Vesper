# Vesper

Roman illustré (cyber dusk) lié à Ma Vie. Chaque séance accomplie débloque une scène.
- Données : même Google Sheet que Ma Vie (séances WCT + jours sans alcool).
- Narrations des séances : hébergées avec Ma Vie (gkarnac.github.io/ma-vie).
- Illustrations : `images/ch0/sNN.jpg` (NN = numéro de scène). Sans fichier, une illustration vectorielle de remplacement s'affiche.
- Histoire : `story/chapitre0.md` (source) → `story/chapitre0.js` (utilisé par l'app).
